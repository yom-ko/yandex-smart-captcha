# Agent context: source of truth

This directory is the **only** place to edit AI-agent context files.

Everything else is generated by [`build-agent-context.sh`](../build-agent-context.sh) that is run automatically by the pre-commit hook in [`.githooks/`](../.githooks).

| Source | Generated targets |
| --- | --- |
| `project.md` | `AGENTS.md`, `.claude/CLAUDE.md`, `.github/copilot-instructions.md` |
| `rules/<name>.md` | `.claude/rules/<name>.md`, `.cursor/rules/<name>.mdc`, `.github/instructions/<name>.instructions.md` |
| `skills/<name>/` | `.claude/skills/<name>/`, `.cursor/skills/<name>/`, `.github/skills/<name>/` |

## Ownership rules

The following directories/files are **fully owned by the generator** and are wiped and rewritten on every run:

- `AGENTS.md`, `.claude/CLAUDE.md`, `.github/copilot-instructions.md`
- `.claude/rules/`, `.cursor/rules/`, `.github/instructions/`
- `.claude/skills/`, `.cursor/skills/`, `.github/skills/`

**Never add manually maintained files to those locations** – anything placed there by hand will be silently deleted the next time the script runs. If you need a manually maintained rule/skill instruction that shouldn't be generated, keep it outside of these directories entirely.

## Regenerating

```bash
./build-agent-context.sh
```

The pre-commit hook regenerates automatically whenever `.agents/` changes are staged; running it manually is only needed to preview the result locally.
